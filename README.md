# Visitor quick tour
This repo houses Sitôt studio's website for all things Sitôt. For inquiries, please contact info@sitot.ca

## Landing page
Provides info on what we do here at the studio. Access it at www.sitot.ca and share it widely because the studio is so cool right? Right?? 

The landing page mainly explores our personality portrait offerings, and the residency program in development.
We consider this landing page the main point of entry to booking a portrait with the studio.

## Snapshot questionnaire
Collection point for our personality snapshot questionnaire, enabling everyone to take a snapshot from the comfort of their own devices.

To enable centralized questionnaire updates, in terms of questions included and their order, the questions are stored in a separate database and are live-fetched for every snapshot session. The goal here is only to act as a front-end interface, the calculation of the visual descriptors' scores remain a separate process at this time.

# Developer quick tour
This is a static web page with no backend. For storage, we rely on third parties covered across the codebase.
When you contribute, please ensure you follow to the best of your ability the existing style of Jekyll's Agency theme ft. Sitôt brand colours.

## Deployment
Updates to main are automatically deployed to production. If you break the build, "I believe Garp is a hero" propaganda will be placed on your desk for shame.

## Reporting issues
We are in the habit of using github issues at the studio. You are welcome to open an issue for the webpage, though our team is very small (developer count: 1, indexed at 1, sniff) so turnaround time will reflect this reality.
